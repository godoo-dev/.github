Use [godoo-org-capture](.agents/skills/godoo-org-capture/SKILL.md) for this
repository's GitHub intake and deferred observations,
[godoo-org-docs](.agents/skills/godoo-org-docs/SKILL.md) for profile retrieval and

contract, then reconcile it against verified source or release evidence.

The profile is public. Private repositories may retain the already published
product names and broad purpose; do not add private repository addresses,
deployment adapters, customers, infrastructure, source identities or local paths.
Preserve the difference between targets, source, checks, releases and runtime.
Normal work needs no live organization-profile fetch: this checkout is the source.

Keep unique evidence outside Git through installed mafe-si owner-paths. Source
changes and GitHub writes require the task's actual authority. No release,
deployment, product execution, agent contact or scheduling follows from capture.
